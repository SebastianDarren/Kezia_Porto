# Kezia Portfolio: "Create by Kezia" menu

Vite + vanilla JS. No framework.

## Run
- `npm run dev` develop
- `npm run build` outputs `dist/` (relative paths, works on any host/sub-folder)
- `npm run preview` test the build

## Where to edit
- `data.js`: ALL content (projects, texts, links, LinkedIn/Instagram/email, tools)
- `style.css`: palette tokens at the top (`:root`)
- `main.js`: pages, router, animations
- `public/img/`: optimized images (webp)

## Pages (hash routes)
`#/` home · `#/menu` · `#/dish/<slug>` (6 dishes) · `#/about` · `#/contact`
